# Atlas Goods

A premium headless commerce storefront showing catalog routes, product detail pages, cart behavior, and checkout handoff powered by Wix Headless.

This website is powered by Wix Headless and built using [wix-headless.dev](https://www.wix-headless.dev).

## Live Site

- [https://atlasgoods.store](https://atlasgoods.store)

## Source

- [https://github.com/wix-incubator/atlasgoods](https://github.com/wix-incubator/atlasgoods)

## What It Showcases

- Commerce experience built as a custom headless website
- Wix-managed backend capabilities surfaced through a custom Astro front end
- Public `llms.txt` and `robots.txt` configured through the Wix SEO txt APIs
- Deployment with `wix release`

## Local Development

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
```
